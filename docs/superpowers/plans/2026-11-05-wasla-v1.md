# WASLA v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the WASLA backend API, public scan page, admin panel and Expo owner app, fully working and tested locally, with a written VPS deployment guide.

**Architecture:** One Laravel 13 app in `backend/` serves the JSON API for the mobile app, server-rendered Blade pages for visitors, and a Filament admin panel. Business rules live in small service classes that controllers and admin actions share. The Expo app in `mobile/` talks only to the API and holds no third-party keys.

**Tech Stack:** PHP 8.3+, Laravel 13, Sanctum, Filament, Pest, MariaDB 10.4 locally and MySQL in production, Expo with Expo Router and TypeScript, jest-expo.

**Spec:** `docs/superpowers/specs/2026-11-05-wasla-design.md`. Read it before starting any task. It wins over this plan on any conflict.

## Global Constraints

- Laravel 13 on PHP 8.3 or newer. XAMPP's PHP 8.2 stays untouched; run all backend commands with PHP 8.3+.
- Standard migrations and Eloquent or bound queries only, compatible with both MariaDB 10.4 and MySQL. No raw SQL built from strings.
- No third-party keys in mobile code. All payment and moderation calls go through Laravel.
- Mobile uses React Native and Expo core components only, in white and royal blue (`#4169E1` base, darkened where text needs 4.5:1 contrast). Touch targets at least 44 px, visible loading and error states, SVG icons, no emoji icons, reduced motion respected.
- All user-facing strings are translatable. Turkish is the default, English the second language. Dates use `Europe/Istanbul` for display and scheduling, UTC in storage.
- Every write uses a Form Request. Every API route has a named rate limit. Every owner resource has a policy.
- Plate and owner name never appear publicly. Moderation sends only text to OpenAI, never user or car identifiers.
- No secrets in git. `.env.example` lists every variable with an empty or safe value.
- Commit messages end with: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## Review Focus

- A visitor has chat open when the owner turns on stealth, lets the tag expire, or is suspended: the next poll and send must stop and reveal nothing (Task 10).
- A double tap or network retry on claim: the same user gets the same car back, no duplicate car, and expiry dates unchanged (Task 3).
- A payment callback arrives twice, out of order, with a wrong amount, or after the tag changed hands: the subscription is extended at most once and only on a verified payment (Task 13).
- The in-app scanner reads a non-WASLA QR code, a URL on another domain, or a revoked tag: a clear message, and no request carrying an unrelated URL (Tasks 3 and 19).
- Expiry at the exact second, and dates around midnight in Istanbul: a tag is expired at `expires_at`, and a reminder fires on the Istanbul calendar date (Tasks 3 and 11).
